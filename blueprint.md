# **App Name**: MirbInvestments: Simplify Crypto

## Core Features:

- Secure User Authentication: User-friendly registration and login with Two-Factor Authentication (2FA) for enhanced security.
- Crypto Shop: The Crypto Shop allows users to easily purchase curated crypto bundles.
- Interactive Portfolio Dashboard: Display user's crypto holdings, total portfolio value, and performance metrics in a clear, concise dashboard.
- AI-Driven Market Insights: AI-powered insights tool delivers accessible market analysis and token spotlights, transforming complex data into easy-to-understand information (Disclaimer: For educational purposes, not financial advice). The AI will use the 'tool' to simplify language for complex crypto terms.
- Support Center: Comprehensive FAQ and contact form for user support and issue resolution.
- Purchase History: Display purchase history so users can review past transactions.
- User Profile Settings: Settings panel for users to manage their profile and settings, including the option to change passwords and review their User ID.

## Style Guidelines:

- Primary background: Onyx Black (#0D0D0D) for a sleek, high-tech feel.
- Secondary background: Charcoal (#2B2D42) for cards and modals.
- Primary accent: Maisport Neon Green (#2FE93D) for CTAs, growth charts, and positive elements. The green hue symbolizes growth, consistent with investments and financial success. Using a vibrant, saturated version of this color evokes the modern aesthetic appropriate for a high-tech investment platform.
- Secondary accent: MIRB Signal (#C3E7C2) for premium actions and special UI elements.
- Destructive accent: Strategic Red (#EF233C) for losses and alerts.
- Text: Finance White (#EDF2F4) for headlines and body text.
- Subtle elements: Platinum Gray (#8D99AE) for icons, borders, and grid lines.
- Crypto-specific icons: BNB Gold (#F0B90B) for cryptocurrency iconography.
- Headlines: 'Inter' (sans-serif) Bold/ExtraBold.
- Body Text: 'Inter' (sans-serif) Regular/Medium.
- Minimalist, clear icons with crypto-specific icons in BNB Gold.
- Mobile-first design with full responsiveness for desktop; intuitive navigation with a hamburger menu for mobile and top-level navigation for desktop.
- Subtle transitions and animations for a smooth user experience.
